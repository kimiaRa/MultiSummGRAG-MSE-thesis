Cookies on Neighbourly

Cookies on Neighbourly

Neighbourly has a transparent cookie usage policy. Below is a summary, but if you would like more information please visit our Cookies policy page.

We use cookies & data to

  • Allow the website to operate (manage logins/allow videos to play/work within EU GDPR/submit forms etc)
  • Understand how people use the website
  • Improve the website and develop new features
  • Manage network servers to ensure the website has no downtime
  • Assess the success of external advertising and optimise user journeys
  • Allow Neighbourly content to be shared through social media

Things we don't do

  • Sell user data to third parties (Neighbourly is a certified B Corp)
  • Track user behaviour off site
